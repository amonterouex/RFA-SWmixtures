# RFA - SW mixtures

Source code and simulations accompanying preprint "*A Unified Rational-Function-Approximation for Square-Well, Square-Shoulder, and Nonadditive Hard-Sphere mixtures*".

The repository contains two folders:
- **Mathematica/**: contains the Mathematica notebook implementing the theoretical framework presented in the paper.
- **MCsimulations/**: contains the raw _.txt_ files with Monte Carlo simulation data generated for this work.

## :open_file_folder: Folders

### :ferris_wheel: Mathematica/

The source code is provided as a Mathematica notebook and is intended as a transparent research implementation rather than a standalone software package.

**Dependencies**:  Wolfram Mathematica (tested with version 14.0).

**Execution**: The notebook includes instructions on how to use the code, with dedicated cells for setting and modifying the required parameters.  

### :classical_building: MCsimulations/

This folder contains the raw _.txt_ files with the simulation data generated for this work. The parameters used in each simulation are specified within the corresponding _.txt_ file.
